> Один и тот же инструмент могут применять как легитимные, так и вредоносные программы, но сам WinDivert вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов относит файлы WinDivert к инструментам повышенного риска или хакерским средствам. В результате файл удаляется и помещается в карантин. Такое обнаружение обычно называется `WinDivert` либо `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог с запретом в исключения антивируса или отключите проверку PUA — потенциально нежелательных приложений. Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы хорошо понимаете настройку исключений, предпочтительнее добавить исключение; если нет — рекомендуется отключить обнаружение PUA.

## ⚙️Установка и запуск

1. Активируйте безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и укажите провайдера, отличного от "Поставщик по умолчанию"
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", нажмите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * Windows 11 позволяет включить Secure DNS в параметрах самой ОС — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 это рекомендуемый вариант
    * Владельцам роутеров Keenetic нужно включить в настройках пункт "Транзит запросов". При его отключении Secure DNS на компьютере может работать некорректно

2. Загрузите zip- или rar-архив со [страницы последнего релиза](https://github.com/Rivetforpanel/zapret-discord-youtube/releases/latest)

3. Откройте свойства архива и включите "Разблокировать". Для архивов, скачанных через 7-Zip или PeaZip, этот пункт можно не выполнять

4. Извлеките файлы в каталог, в пути к которому нет кириллицы и специальных символов

5. Запустите подходящий скрипт
    * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для добавления стратегии в автозагрузку выберите **`service.bat`** -> `Install Service` -> *нужная стратегия*

## ℹ️Что делают основные файлы

- [**`general.bat ...`**](./general.bat) — запускает стратегию напрямую

  Такой запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому **перебирайте варианты ALT, FAKE и другие, пока не найдёте подходящий для себя**

- [**`service.bat`**](./service.bat) — установка автозапуска и дополнительные операции:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск служб (services.msc)</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из служб
  - **`Check Status`** — показать состояние обхода и служб, включая автозапущенную стратегию и WinDivert
  - **`Game Filter`** — включить или выключить обход для игр и других сервисов, работающих с UDP и TCP-портами выше 1023.  
  **После изменения режима стратегию необходимо перезапустить.**  
  В скобках отображается текущее состояние: включено или выключено.
  - **`IPSet Filter`** — изменить режим обхода ресурсов из `ipset-all.txt`.  
  Это может помочь при проверке ресурса, который без zapret работает, а с ним — нет.  
  В скобках показывается текущий режим:
    - `none` — IP-адреса не проходят проверку
    - `loaded` — проверяются IP-адреса, входящие в список
    - `any` — под фильтр попадает любой IP-адрес  
  - **`Auto-Update Check`** — включить или отключить автоматический поиск обновлений
  - **`Replace active fakes`** — заменить используемый fake на другой из каталога `bin`
  - **`Update IPSet List`** — скачать из репозитория актуальный `ipset-all.txt`
  - **`Update Hosts File`** — обновить hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений
  - **`Run Diagnostics`** — найти распространённые причины неисправности zapret.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; иногда это возвращает неожиданно переставший работать клиент
  - **`Run Tests`** — открыть проверку стратегий:
    - `Standard tests` — тестирование сайтов из `utils/targets.txt`
    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Частые вопросы и неисправности

### После запуска `general*` нет видимого результата

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe. Его можно увидеть на панели задач.  
Если этого не произошло, обратитесь к [#522](https://github.com/Rivetforpanel/zapret-discord-youtube/issues/522)

### Не подошла ни одна стратегия
- Откройте командную строку с правами администратора
- Выполните по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не подключается Telegram в браузере
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если используемый hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открывшегося блокнота
  - В открывшемся каталоге найдите `hosts` и откройте его текстовым редактором от имени администратора
  - Вставьте скопированное в конец `hosts` либо замените ранее добавленный аналогичный фрагмент
  - Сохраните изменения и снова проверьте соединение. Если результата нет, убедитесь, что файл действительно был сохранён.

#### Работа веб-версии не гарантируется. Если этот способ не помог, используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/Rivetforpanel/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или перестал помогать

> [!IMPORTANT]
> **Стратегии могут со временем терять работоспособность.**
> Вначале выбранная стратегия может работать, но после обнаружения перестать обходить блокировку.
> В проекте есть много разных вариантов. Если готовые стратегии не подходят, создайте новую на основе одной из них, изменив её параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- В `service.bat` запустите `Run Diagnostics` и убедитесь, что ошибок нет

- Проверьте, присутствует ли адрес нужного ресурса в списках доменов или IP

- Попробуйте другие варианты, в том числе **`ALT`** и **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация: [#765](https://github.com/Rivetforpanel/zapret-discord-youtube/issues/765)

### Полная переустановка или обновление
- Сохраните добавленные вами ресурсы и другие данные
- Перезапустите компьютер
- Откройте `service.bat` -> `Remove Services`
- Затем выполните `service.bat` -> `Run Diagnostics`; исправьте найденные ошибки и в конце ответьте Y
- Удалите старый каталог запрета
- Скачайте свежую версию со [страницы релизов](https://github.com/Rivetforpanel/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Нажмите ПКМ по архиву, откройте свойства и, если внизу справа есть "Разблокировать", установите флажок, нажмите "Применить" и "ОК"
- Распакуйте архив в новый каталог в корне диска; путь не должен содержать пробелов и специальных символов
- Запускайте разные скрипты `general` и проверяйте интернет-ресурсы. Если доступ не появился, закройте программу через значок замка на панели задач и выберите другую стратегию
- После выбора рабочей стратегии добавьте её в автозапуск через `service.bat` -> `Install Service` -> нужная стратегия

### Игра или приложение перестаёт работать при включённом запрете

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

- Следуйте инструкции: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё есть среди служб

1. Найдите имя службы в командной строке Windows. Откройте её через Win+R, введя `cmd`, и выполните:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что [Secure DNS настроен](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Переберите остальные стратегии, особенно если раньше доступ работал.
- См. также [#251](https://github.com/Rivetforpanel/zapret-discord-youtube/discussions/251)

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS включён](#%EF%B8%8Fиспользование)
- Сначала желательно определить стратегию, с которой открывается YouTube, и запустить её
- В `service.bat` перейдите в `Run Diagnostics` и очистите кэш Discord
- Проверьте, заработало ли приложение Discord после очистки
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей
- Если браузерная версия также не подключается, снова проверьте все стратегии: YouTube и Discord могут работать на разных вариантах
- См. также [#252](https://github.com/Rivetforpanel/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/Rivetforpanel/tg-ws-proxy)
- Либо воспользуйтесь бесплатными MTProto-прокси из интернета

### Не подключаются игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Для начала используйте универсальную последовательность:
- в `service.bat` обновите ipset и активируйте `Game Filter`
- если это не помогло, дополнительно включите режим `ipset any`

Учитывайте, что `ipset any` может нарушить доступ к большому числу сайтов. Не оставляйте этот режим включённым постоянно: определите IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`

Если результата нет, создайте обсуждение в [Discussions](https://github.com/Rivetforpanel/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

## 🗒️Как добавить другие адреса

Список ресурсов для обхода расширяется через следующие файлы:
- **`list-general-user.txt`** — домены; поддомены будут учтены автоматически
- **`list-exclude-user.txt`** — домены, которые нужно исключить, например когда IP сети есть в `ipset-all.txt`, но конкретный домен фильтровать не требуется
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые нужно исключить
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
