>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Некоторые антивирусы считают файлы WinDivert потенциально опасными или относят их к хакерским инструментам. В результате файл удаляется и отправляется в карантин. Название такого обнаружения обязательно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог с zapret в исключения антивируса либо отключите обнаружение PUA (потенциально нежелательных приложений). Например, Kaspersky содержит настройку "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы хорошо понимаете настройки исключений, рекомендуется добавить исключение. При отсутствии такой уверенности отключите обнаружение PUA.

## ⚙️Использование

1. Настройте безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и выберите поставщика, отличного от "Поставщик по умолчанию"
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * В Windows 11 Secure DNS можно включить непосредственно в настройках системы. Инструкция находится [здесь](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 этот вариант рекомендуется
    * Владельцам роутеров Keenetic нужно включить настройку "Транзит запросов". Если ее отключить, Secure DNS на компьютере может работать некорректно

2. Получите zip/rar-архив со [страницы последнего релиза](https://github.com/Rivetforpanel/zapret-discord-youtube/releases/latest)

3. Откройте свойства архива и отметьте "Разблокировать". Для архивов, открываемых через 7-Zip или PeaZip, этот пункт можно пропустить

4. Распакуйте архив в каталог без кириллицы и специальных символов в пути

5. Запустите нужный скрипт
    * Для поиска подходящей стратегии: **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для добавления стратегии в автозапуск: **`service.bat`** -> `Install Service` -> выберите подходящую стратегию

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) запускает стратегию вручную

  Такой запуск удобен для проверки стратегий. Результат зависит от множества факторов, поэтому **перебирайте разные варианты, включая ALT и FAKE, пока не найдете рабочий для себя**

- [**`service.bat`**](./service.bat) содержит установку автозапуска и дополнительные операции:
  - <ins>**`Install Service`** добавляет выбранную стратегию в автозапуск через services.msc</ins>
  - **`Remove Services`** удаляет стратегию и WinDivert из служб
  - **`Check Status`** показывает состояние обхода и служб, включая стратегию автозапуска и WinDivert
  - **`Game Filter`** меняет режим обхода для игр и других сервисов, использующих UDP и TCP-порты выше 1023.  
  **После изменения параметра стратегию нужно перезапустить.**  
  Значение в скобках показывает текущий статус: включено или выключено.
  - **`IPSet Filter`** управляет обходом сервисов из `ipset-all.txt`.  
  Опция пригодится при проверке ресурса, который без zapret работает, а с ним перестает открываться.  
  В скобках отображается состояние:
    - `none` - проверка IP не применяется
    - `loaded` - IP сверяется со списком
    - `any` - под фильтр попадает любой IP  
  - **`Auto-Update Check`** включает или отключает автоматическую проверку обновлений
  - **`Replace active fakes`** заменяет используемый фейк на другой из каталога `bin`
  - **`Update IPSet List`** загружает актуальный `ipset-all.txt` из репозитория
  - **`Update Hosts File`** обновляет hosts <ins>для восстановления веб-версии Telegram и подключения к голосовому чату Discord</ins>
  - **`Check for Updates`** проверяет наличие обновлений
  - **`Run Diagnostics`** ищет распространенные причины неисправности zapret.  
  В конце диагностики можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`, что иногда возвращает работоспособность приложения
  - **`Run Tests`** запускает проверку доступных стратегий:
    - `Standard tests` проверяет сайты из `utils/targets.txt`
    - `DPI checkers` проверяет DPI у разных провайдеров, включая Cloudflare и Amazon

## ☑️Распространенные вопросы и проблемы

### После запуска `general*` ничего не произошло

При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe, который можно увидеть на панели задач.  
Если его нет, обратитесь к [#522](https://github.com/Rivetforpanel/zapret-discord-youtube/issues/522)

### Не нашлось подходящей стратегии
- Откройте командную строку с правами администратора
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезапустите компьютер

### Не открывается Telegram в браузере

В **`service.bat`** выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого блокнота
  - Откройте файл `hosts` в созданной папке через текстовый редактор, запущенный от имени администратора
  - Вставьте скопированный текст в конец `hosts` или замените ранее добавленные аналогичные строки
  - Сохраните файл и снова проверьте подключение. Если результата нет, убедитесь, что изменения действительно сохранились.

#### Работа не гарантируется. Если способ не помог, используйте [Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/Rivetforpanel/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или перестал работать

> [!IMPORTANT]
> **Стратегии со временем могут терять работоспособность.**
> Обнаружение определенной стратегии может произойти не сразу: она способна работать некоторое время, а затем перестать.
> Здесь собрано много вариантов обхода. Если ни один не подходит, создайте собственную стратегию на основе одной из опубликованных и измените ее параметры.
> Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте отсутствие ошибок в `service.bat` -> `Run Diagnostics`

- Убедитесь, что нужный адрес входит в доменные или IP-списки

- Проверьте остальные стратегии, включая **`ALT`** и **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация: [#765](https://github.com/Rivetforpanel/zapret-discord-youtube/issues/765)

### Как полностью обновить или переустановить проект?
- Сохраните ресурсы и данные, которые добавляли самостоятельно
- Перезапустите устройство
- Откройте `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; при наличии ошибок исправьте их, затем в конце выберите Y
- Удалите старую папку zapret
- Загрузите свежую версию [со страницы релизов](https://github.com/Rivetforpanel/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Откройте свойства архива правой кнопкой мыши. Если внизу справа есть "Разблокировать", отметьте пункт, нажмите "Применить" и "ОК"
- Распакуйте архив в новую папку в корне диска; в пути не должно быть пробелов и специальных символов
- Запускайте разные `general`-скрипты и проверяйте доступ к ресурсам. Если интернет-ресурсы не открываются, закройте программу через значок замка на панели задач и выберите другую стратегию
- Найдя рабочий вариант, добавьте его в автозапуск через `service.bat` -> `Install Service`

### Игра или приложение не работает при включенном zapret

- В `service.bat` проверьте, что `Game Filter` имеет статус **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может повлиять на неожиданные для вас ресурсы.

### Античит обнаруживает WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноименными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert остается среди служб

1. Найдите имя службы командой в Windows: Win+R, затем `cmd`:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться
- Если прежняя стратегия перестала работать, протестируйте остальные
- См. также [#251](https://github.com/Rivetforpanel/zapret-discord-youtube/discussions/251)

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) настроен
- Сначала определите стратегию, на которой открывается YouTube, и запустите ее
- В `service.bat` перейдите в `Run Diagnostics` и очистите кэш Discord
- Проверьте, помогла ли очистка кэша в приложении Discord
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно пользоваться ей
- Если браузерная версия также не работает, снова проверьте все стратегии. YouTube и Discord могут работать на разных стратегиях
- См. также [#252](https://github.com/Rivetforpanel/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/Rivetforpanel/tg-ws-proxy)
- Либо подключите бесплатный MTProto-прокси из интернета

### Не запускаются игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Начните с универсальной последовательности:
- через `service.bat` обновите ipset и включите `Game Filter`
- если это не помогло, дополнительно включите `ipset any`

Учтите: режим `ipset any` может нарушить открытие множества сайтов. Не оставляйте его включенным постоянно. Определите IP-адреса, которые использует игра, и добавьте их в `ipset-all.txt`

Если результат не изменился, создайте обсуждение в разделе [Discussions](https://github.com/Rivetforpanel/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

## 🗒️Добавление адресов прочих ресурсов

Дополнительные адреса можно указать в следующих файлах:
- **`list-general-user.txt`** содержит домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** исключает домены, например когда IP-сеть есть в `ipset-all.txt`, но отдельный домен из нее фильтровать не нужно
- **`ipset-all.txt`** предназначен для IP-адресов и подсетей
- **`ipset-exclude-user.txt`** исключает IP-адреса и подсети
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
